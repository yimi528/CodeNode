# CodeNode 主题

设置 → 常规 → 主题提供日间、夜间和无色玻璃三项。首次启动及已移除主题的旧配置会使用日间主题。有效的主题选择保存在本机，切换主题时会话、草稿、当前模型和面板宽度继续可用。

三个主题共用参考分支的窗口布局和石墨色工作区。画布、侧栏、标题栏和对话编辑区都是不透明的。无色玻璃采用中性灰表面，运行状态与危险操作仍使用语义颜色。

配色由 `config/ui.themes.json` 提供，`src/styles.css` 按参考分支的顺序加载各段样式。运行 `npm run build --ignore-scripts` 后，可用 `npm run test:bright-theme-ui` 验证主题切换和不透明窗口。
